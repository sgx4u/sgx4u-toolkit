# @sgx4u/object functions

Parameters are one flat object unless the function takes a single value. A default is the value used when the field is omitted. Per-call fields replace a `createObject` config.

`cloneContinue` and `mapSkip` are sentinels, not functions.

## Shared types

Exported from the root, and the JSON types again from `/json-patch`:

`PlainObject`, `JSONValue`, `JSONArray`, `JSONObject`, `PathSegment`, `ObjectPath`, `PathStyle`, `ArrayMerge`, `PrototypeKeys`, `CircularPolicy`, `KeyCase`, `EmptyValue`, `PrototypePolicy`, `ObjectConfig`, `ObjectDiff`, `ObjectKeys`, `ObjectValues`, `ObjectEntries`, `PartialDeep`, `RequiredDeep`, `ReadonlyDeep`, `WritableDeep`, `MergeDeep`, `Paths`, `PathValue`, `PickDeep`, `OmitDeep`, `ObjectInstance`.

`PickDeep` resolves literal string paths. `OmitDeep` is a deep partial. `Paths` is limited to five levels.
