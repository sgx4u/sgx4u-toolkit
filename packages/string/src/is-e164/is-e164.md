# `isE164`

Shape check for an E.164 number: optional `+` and 8 to 15 digits, first digit non-zero. This is not a country phone validator.

## Import

```ts
import { isE164 } from "@sgx4u/string";
```

## Signature

```ts
function isE164(value: unknown): boolean;
```

## Examples

```ts
isE164("value");
```

## Edge cases

A non-string returns `false`.
