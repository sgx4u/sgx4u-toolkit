# Function reference

Every export in `@sgx4u/number`. Parameters shown in the signature are passed directly when there is one value, and as one flat object when there are several. Optional parameters are marked with `?`. Defaults are the values in the signature or the defaults documented on `createNumber`.

`createNumber(config?)` returns a frozen object with every root function. Per-call values override the config. Word functions are not on that object. Import `@sgx4u/number/words/en` or `@sgx4u/number/words/en-IN` for those.
