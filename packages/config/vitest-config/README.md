# @sgx4u/vitest-config

Vitest preset: Node environment, tests in `src/**/*.test.ts`.

## Install

```sh
pnpm add -D @sgx4u/vitest-config vitest
```

## Examples

```ts
import { definePackageVitestConfig } from "@sgx4u/vitest-config";

export default definePackageVitestConfig();
```
