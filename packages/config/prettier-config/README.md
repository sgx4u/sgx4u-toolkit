# @sgx4u/prettier-config

Shared Prettier options: semicolons, double quotes, trailing commas, 80 columns.

## Install

```sh
pnpm add -D @sgx4u/prettier-config prettier
```

## Examples

```json
{
    "prettier": "@sgx4u/prettier-config"
}
```
