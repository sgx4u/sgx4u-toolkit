# Function reference

Every export of `@sgx4u/array`, `@sgx4u/array/async`, and `@sgx4u/array/combinatorics`. A function that takes one value takes that value directly. A function that takes several takes one flat object. Optional fields use the default in the parameters column when a default is part of the type docs.

The three factories return a frozen object of the other functions on that entry. `createArray` omits itself.
