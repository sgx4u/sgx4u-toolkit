Summary: First release of @sgx4u/array.

Added: `createArray` returns immutable array helpers with shared defaults for `equals`, locale-aware sorting, and `random`.

The root entry covers guards, slicing, grouping, sets, sorting, updates, reshape, generation, sampling, aggregation, pagination, and sequence diff. `@sgx4u/array/async` adds concurrent async iteration. `@sgx4u/array/combinatorics` adds products, combinations, permutations, the power set, and pairs.
