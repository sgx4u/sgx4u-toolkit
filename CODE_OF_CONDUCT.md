# Code of Conduct

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report a community concern to [@sgx4u](https://github.com/sgx4u). Report a security vulnerability through [GitHub private vulnerability reporting](https://github.com/sgx4u/sgx4u-toolkit/security/advisories/new).
